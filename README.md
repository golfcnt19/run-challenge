# Run Challenge — ตารางคะแนนกิจกรรมวิ่งสะสม 7 ทีม

เว็บ static หน้าเดียว อ่านข้อมูลจาก Google Sheets แล้วคิดคะแนน/จัดอันดับให้อัตโนมัติ
แอดมินกรอกข้อมูลในชีตอย่างเดียว ไม่ต้องแตะโค้ด

- **ช่วงกิจกรรม** 15 ก.ย. – 30 ต.ค. 2569 (46 วัน) · 7 กลุ่ม (A–G) กลุ่มละ 5 คน
- **กติกา** วิ่งสวน/วิ่งลู่ 1 กม. = 1 คะแนน · เดิน 10,000 ก้าว = 5 · ปั่น 20 กม. = 5 · กีฬา (แบด เทนนิส ฟุตบอล ว่ายน้ำ บาส) 60 นาที = 5 ขั้นต่ำ 15 นาที (คิดตามสัดส่วน)
  รวมทุกกิจกรรมในวันเดียวได้ แต่ **ไม่เกิน 5 คะแนน/คน/วัน** · คะแนนทีม = ผลรวมสมาชิก
- **การ์ดพิเศษ** ทีมละ 3 ใบ/วีค: 🎒 เดอะแบก · ✖️2 คูณสอง · 🛡️ Block — กติกาเต็มใน [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## ตั้งค่าครั้งแรก

1. สร้าง Google Sheets ใหม่ 1 ไฟล์ ตั้งชื่อแท็บ 3 แท็บให้ตรงเป๊ะ: `teams` `runs` `config`
2. ก๊อปหัวคอลัมน์และข้อมูลจาก [sample-data/](sample-data/) ไปวาง (แท็บ `teams` กับ `config` ใช้ได้เลย ส่วน `runs` ให้วางแค่แถวหัว)
3. แชร์ → **ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน**
4. ก๊อป ID จาก URL `https://docs.google.com/spreadsheets/d/`**`<ID>`**`/edit` ไปวางใน [js/config.js](js/config.js) แล้วเปลี่ยน `USE_SAMPLE` เป็น `false`

## วิธีกรอกข้อมูล (แท็บ `runs`)

1 แถว = 1 การส่งผล

| date | runner | activity | amount | note |
|---|---|---|---|---|
| 2026-09-15 | Jay | run | 5.2 | |
| 2026-09-15 | Koi | เดิน | 10000 | |
| 2026-09-16 | Golf | ปั่น | 18.5 | สวนรถไฟ |

- `date` รูปแบบ `YYYY-MM-DD` (ตั้ง format คอลัมน์เป็น Plain text กันชีตแปลงเอง)
- `runner` ชื่อต้องตรงกับที่อยู่ในคอลัมน์ `members` ของแท็บ `teams` (ไม่สนตัวพิมพ์ใหญ่-เล็ก)
- `activity` พิมพ์ไทยหรืออังกฤษก็ได้: `run`/`วิ่งสวน` · `treadmill`/`วิ่งลู่` · `walk`/`เดิน` · `bike`/`ปั่น` · `badminton`/`แบด` · `tennis`/`เทนนิส` · `football`/`ฟุตบอล` · `swim`/`ว่ายน้ำ` · `basketball`/`บาส` · `gym`/`ฟิตเนส` · `yoga`/`โยคะ` · `jumprope`/`กระโดดเชือก`
- `amount` เป็นกม. สำหรับวิ่ง/ปั่น, ก้าวสำหรับเดิน, **นาที**สำหรับกีฬา
- แถวที่กรอกผิด (ชื่อไม่ตรง / วันที่นอกช่วง / กิจกรรมไม่รู้จัก) เว็บจะ **ไม่นับ** และแสดงในกล่องเตือนด้านบนพร้อมเลขแถว

## หน้ากรอกผล (`entry.html`) — หัวหน้าทีมกรอกเองผ่านเว็บ

หน้ากรอกส่งข้อมูลไปที่ Google Apps Script ที่ผูกกับชีต (ตัวเดียวที่มีสิทธิ์เขียน) ตรวจ PIN ทีมแล้วค่อย append ลงแท็บ `runs`

ติดตั้งครั้งเดียว:
1. เปิดชีต → **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม วาง [apps-script/Code.gs](apps-script/Code.gs) ทั้งไฟล์
2. แก้ `PINS` ด้านบนไฟล์ (PIN ทีม A–G + ADMIN) แล้วบันทึก
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้ใหม่** → ประเภท *เว็บแอป* · ดำเนินการในฐานะ *ฉัน* · ผู้เข้าถึง *ทุกคน* → Deploy → อนุญาตสิทธิ์
4. ก๊อป URL เว็บแอป (ลงท้าย `/exec`) วางใน [js/config.js](js/config.js) ที่ `ENTRY_URL` → push

แก้โค้ดใน Apps Script ภายหลังต้อง *จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่* ไม่งั้น URL เดิมรันโค้ดเก่า

สคริปต์ตรวจให้: PIN ตรงทีม · ชื่ออยู่ในทีม · วันที่อยู่ในช่วงและไม่ล่วงหน้า · จำนวน > 0 และไม่เกินจริง
และบันทึกเพิ่ม 2 คอลัมน์ `submitted_at`, `submitted_by` ไว้ตรวจสอบย้อนหลัง (เว็บไม่ใช้)

## ปรับกติกา (แท็บ `config`)

| key | ความหมาย |
|---|---|
| `title` | ชื่อกิจกรรมบนหัวเว็บ |
| `start_date` / `end_date` | ช่วงกิจกรรม |
| `daily_cap` | เพดานคะแนนต่อคนต่อวัน |
| `points_per_run_km` | วิ่ง 1 กม. ได้กี่คะแนน |
| `walk_steps_for_full` | เดินกี่ก้าว = เต็มวัน |
| `bike_km_for_full` | ปั่นกี่กม. = เต็มวัน |
| `sport_minutes_for_full` | กีฬากี่นาที = เต็มวัน (ค่าเริ่มต้น 60) |
| `sport_min_minutes` | กีฬาต่ำกว่ากี่นาทีไม่นับ (ค่าเริ่มต้น 15) |

ถ้ากติกาเปลี่ยนแบบที่ตัวเลขไม่พอ (เช่น เพิ่มโบนัส) แก้ที่ [js/scoring.js](js/scoring.js) จุดเดียว
