# คู่มือดูแลระหว่างกิจกรรม (Run Challenge)

ทุกอย่างที่เป็น "ข้อมูล" แก้ในชีตแล้วมีผลทันที **ไม่ต้อง deploy** — deploy เฉพาะเมื่อแก้โค้ดเว็บหรือสคริปต์

| อยากทำอะไร | แก้ที่ไหน | ต้อง deploy? |
|---|---|---|
| เปลี่ยน/เพิ่ม/ลดสมาชิกทีม | ชีต แท็บ `teams` คอลัมน์ `members` | ไม่ |
| เปลี่ยนชื่อทีม / สีทีม | ชีต แท็บ `teams` | ไม่ |
| แก้วันเริ่ม-จบ, เพดานคะแนน, อัตราแปลง | ชีต แท็บ `config` | ไม่ |
| ลบ/แก้รายการที่กรอกผิด | ชีต แท็บ `runs` (หรือหัวหน้าทีมกด 🗑 ในหน้ากรอก) | ไม่ |
| ยกเลิกการ์ดที่ใช้ผิด | ชีต แท็บ `cards` ลบแถวนั้น (หัวหน้าทีมยกเลิกเองไม่ได้) | ไม่ |
| เปลี่ยนกติกาการ์ด (โควตา/ลำดับ/เพดาน x2) | `js/scoring.js` + `apps-script/Code.gs` | ใช่ ทั้งคู่ |
| เปลี่ยน PIN ทีม | Apps Script → `PINS` ใน Code.gs | ใช่ (Apps Script เวอร์ชันใหม่) |
| เปลี่ยนสูตรคะแนน (ไม่ใช่แค่ตัวเลข) | `js/scoring.js` + `apps-script/Code.gs` | ใช่ ทั้งเว็บและสคริปต์ |
| แก้หน้าตาเว็บ | `index.html` / `entry.html` / `css` / `js` | ใช่ (push `main`) |

**แก้ `js/scoring.js` แล้วต้องรัน `node --test tests/scoring.test.js`** (pre-commit hook รันให้เองและกัน commit ถ้าไม่ผ่าน) — มีเทสต์ความเท่าเทียมทีม 5 vs 6 คน + การ์ดทั้ง 3 ใบ

## เปลี่ยนสมาชิกทีม — ที่ต้องระวัง

แก้ในแท็บ `teams` คอลัมน์ `members` คั่นด้วยจุลภาค เช่น `Jay, P'Oam, Bird, Thailand, Pong`

- **ชื่อห้ามซ้ำข้ามทีม** — เว็บใช้ชื่อหาว่าอยู่ทีมไหน ถ้าซ้ำจะขึ้นเตือนและนับผิด (ตัวพิมพ์ใหญ่-เล็กถือว่าเหมือนกัน)
- **เปลี่ยนสะกดชื่อ** (เช่น `Tomz` → `Tom`) ต้องแก้ **แถวเก่าในแท็บ `runs` ด้วย** (ใช้ Ctrl+H แทนที่ทั้งคอลัมน์ `runner`) ไม่งั้นแถวเก่าจะขึ้นเตือน "ไม่พบชื่อ" และไม่ถูกนับ
- **ย้ายคนไปทีมอื่น** — แค่ย้ายชื่อใน `members`; **คะแนนเก่าทั้งหมดของคนนั้นจะย้ายตามไปทีมใหม่** (เว็บดูทีมปัจจุบันของชื่อ ไม่ได้จำว่าวันนั้นอยู่ทีมไหน) ถ้าอยากให้คะแนนเก่าอยู่ทีมเดิม ให้ตั้งชื่อใหม่ในทีมใหม่ เช่น `Tom (F)` แล้วกรอกต่อในชื่อนั้น
- **เพิ่มคนที่ 6 / ลดเหลือ 4** ได้เลย — คะแนนทีมคิดสัดส่วนเทียบทีม 5 คน (× 5 ÷ จำนวนคนจริง) และการ์ดนับเต็มเท่ากันทุกทีม จึงยุติธรรมอัตโนมัติ
- **คนออกจากกิจกรรม** แนะนำเก็บชื่อไว้ (คะแนนเก่ายังนับให้ทีม) ถ้าลบชื่อออก แถวเก่าของคนนั้นจะไม่ถูกนับและขึ้นเตือน
- หน้ากรอกอ่าน `members` สด ๆ ทุกครั้ง — dropdown เปลี่ยนตามทันที สคริปต์ Apps Script ก็อ่านแท็บ `teams` สดเช่นกัน ไม่ต้อง deploy

## การ์ดพิเศษ

- ต้องมีแท็บชื่อ `cards` ในชีต (แท็บเปล่าก็ได้ สคริปต์ใส่หัวคอลัมน์ให้เองตอนใช้ครั้งแรก) ถ้าไม่มี หน้ากรอกจะขึ้น "ไม่พบแท็บ cards"
- การ์ดที่ใช้ผิด: ลบแถวในแท็บ `cards` — ทีมนั้นจะได้ใบคืนอัตโนมัติ
- ต้องการเห็นว่าใคร block ใครก่อนเฉลย: ดูในแท็บ `cards` โดยตรง (เว็บซ่อนจนข้ามวัน)
- แถวที่ผิด (ทีม/ชื่อไม่ตรง, block ทีมตัวเอง) เว็บไม่นับและขึ้นเตือนเลขแถวเหมือน `runs`

## เปลี่ยน PIN / แก้สคริปต์

⚠️ **repo เป็น public — `apps-script/Code.gs` ใน repo ใช้ PIN ตัวอย่าง (1111…)** PIN จริงอยู่ในตัวแก้ไข Apps Script เท่านั้น
ถ้าวางโค้ดใหม่จาก repo ต้องใส่ก้อน `PINS` จริงกลับทุกครั้ง ไม่งั้น PIN จะกลายเป็นชุดที่ใครก็เห็นบน GitHub

1. เปิดชีต → ส่วนขยาย → Apps Script → แก้ → Ctrl+S
2. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
3. URL `/exec` เดิม ไม่ต้องแก้เว็บ

กด Ctrl+S อย่างเดียว **ไม่พอ** — URL จะยังรันโค้ดเก่าจนกว่าจะสร้างเวอร์ชันใหม่ (เคยพลาดมาแล้ว)
ตรวจว่าเวอร์ชันใหม่ขึ้นแล้ว: ยิง `{"action":"delete", ...}` ด้วยวันที่นอกช่วง → ต้องตอบ "ไม่พบรายการนี้" (ตัวเก่าจะตอบ "วันที่ก่อนเริ่มกิจกรรม")

## ลบข้อมูลเดโม (ทำวันเริ่มจริง)

แท็บ `runs` → ข้อมูล → สร้างตัวกรอง → กรองคอลัมน์ `note` = `DEMO` → เลือกแถวทั้งหมด → ลบแถว → เอาตัวกรองออก
แล้วตั้ง `start_date` ในแท็บ `config` ตามวันที่ต้องการนับจริง

## เว็บโหลดไม่ขึ้น / ขึ้น 0 ทุกทีม

- ชีตต้องแชร์ "ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน" (ถ้าใครเผลอปิดแชร์ เว็บจะโหลดไม่ได้)
- ชื่อแท็บต้องเป็น `teams` `runs` `config` เป๊ะ ๆ
- หัวคอลัมน์ต้องอยู่แถวที่ 1 และตรงตามชื่อ (`date, runner, activity, amount, note`)
- กล่องเตือนสีเหลืองบนเว็บบอกเลขแถวที่มีปัญหาเสมอ ดูตรงนั้นก่อน
