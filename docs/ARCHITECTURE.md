# สถาปัตยกรรมและเงื่อนไขการคำนวณ (Run Challenge)

## ภาพรวม

```
ผู้ใช้ (มือถือ/คอม)
   │
   ├─ อ่าน ──▶  GitHub Pages  (เว็บ static)  ──fetch CSV──▶  Google Sheets  (ฐานข้อมูล)
   │                                                              ▲
   └─ กรอก ──▶  หน้า entry.html  ──POST JSON──▶  Google Apps Script  ──เขียนแถว──┘
```

ไม่มี server ของตัวเอง ไม่มีค่าใช้จ่าย ไม่มีเครื่องหลับ

## Frontend — เว็บ static ล้วน

- HTML + CSS + JavaScript ธรรมดา (ES modules) ไม่มี framework ไม่มีขั้น build
- 3 หน้า: `index.html` (ตารางคะแนน 3 แท็บ) · `entry.html` (กรอก/ลบผล) · `cards.html` (ใช้การ์ดพิเศษ)
- ไลบรารีเดียว: Chart.js จาก cdnjs · ฟอนต์ Noto Sans Thai จาก Google Fonts
- **คิดคะแนนทั้งหมดในเบราว์เซอร์** (`js/scoring.js`) — ดึงข้อมูลดิบมาแล้วคำนวณเอง
- PWA เบื้องต้น: `manifest.webmanifest` + `icons/` เพิ่มลงหน้าจอโฮมได้ทั้ง iOS/Android

| ไฟล์ | หน้าที่ |
|---|---|
| `js/config.js` | SHEET_ID, ENTRY_URL, สวิตช์ข้อมูลตัวอย่าง — ไฟล์เดียวที่แก้ตอนตั้งค่า |
| `js/sheets.js` | โหลด CSV จากชีต (หรือ `sample-data/`) + parser |
| `js/scoring.js` | กติกาคะแนนทั้งหมด, สถิติทีม/คน/รายวัน |
| `js/format.js` | วันที่ไทย, ตัวเลข, แปลงรูปแบบวันที่ที่ชีตส่งมา |
| `js/app.js` | วาดหน้าตารางคะแนน (การ์ด, สนามแข่ง, รายวัน, รายทีม) |
| `js/entry.js` | หน้ากรอก: ฟอร์ม, ส่ง/ลบผ่าน Apps Script |
| `js/cards.js` | หน้าการ์ด: โควตา, ฟอร์มย่อยต่อใบ, ส่ง action card |
| `css/site.css` | สไตล์ทั้งหมด mobile-first รองรับ dark mode |

## Backend / ฐานข้อมูล — ใช้ของ Google ทั้งหมด

**Google Sheets** = ฐานข้อมูล แชร์ "ทุกคนที่มีลิงก์ → อ่าน"
เว็บอ่านผ่าน `https://docs.google.com/spreadsheets/d/<ID>/gviz/tq?tqx=out:csv&sheet=<แท็บ>` ไม่ต้องใช้ API key

| แท็บ | คอลัมน์ | ความหมาย |
|---|---|---|
| `teams` | team_id, team_name, color, members | ทีมและสมาชิก (คั่นด้วยจุลภาค) |
| `runs` | date, runner, activity, amount, note, submitted_at, submitted_by | 1 แถว = 1 การส่งผล (2 คอลัมน์ท้ายสคริปต์เติมเอง) |
| `config` | key, value | ช่วงวัน, เพดาน, อัตราแปลง, ชื่อกิจกรรม |
| `cards` | date, team_id, card, runner, target_team, target_runner, submitted_at | การ์ดพิเศษที่ใช้ (`carry` / `x2` / `block`) |

**Google Apps Script** (`apps-script/Code.gs`) = API เขียนตัวเดียว deploy เป็น Web App
"ดำเนินการในฐานะฉัน / ผู้เข้าถึงทุกคน" รับ POST JSON (`Content-Type: text/plain` เพื่อเลี่ยง preflight)

- `action` ไม่ระบุ → เพิ่มแถว: ตรวจ PIN ทีม → ชื่ออยู่ในทีม → วันที่ในช่วงและไม่ล่วงหน้า → จำนวนสมเหตุสมผล → append
- `action: "delete"` → ลบแถวที่ตรง date + runner + activity + amount (ลบแถวล่างสุดถ้าซ้ำ) เฉพาะสมาชิกทีมที่ PIN ตรง
- `action: "card"` → ใช้การ์ด: ตรวจ PIN → วันนี้ (เวลาไทย) ในช่วง → โควตา (วันละ 1 ใบ, วีคละชนิดละใบ) → carry ตรวจผู้ให้/ผู้รับในทีม · x2 สุ่มสมาชิกเอง · block ตรวจทีมอื่น+คน → append ลง `cards`
- PIN อยู่ในตัวสคริปต์เท่านั้น (ไม่อยู่ในชีต ไม่อยู่ใน GitHub) · `ADMIN` ใช้แทนได้ทุกทีม
- ใช้ `LockService` กันเขียนชนกัน

## เงื่อนไขการคำนวณคะแนน

### 1. แปลงกิจกรรมเป็นคะแนน (ต่อ 1 รายการ)

| กิจกรรม | สูตร | ตัวอย่าง |
|---|---|---|
| วิ่งสวน / วิ่งลู่ | กม. × `points_per_run_km` (1) | 3.4 กม. → 3.4 |
| เดิน | ก้าว ÷ `walk_steps_for_full` (10,000) × `daily_cap` (5) | 8,000 ก้าว → 4.0 |
| ปั่นจักรยาน | กม. ÷ `bike_km_for_full` (20) × `daily_cap` (5) | 12 กม. → 3.0 |
| 🏸 แบด · 🎾 เทนนิส · ⚽ ฟุตบอล · 🏊 ว่ายน้ำ · 🏀 บาส · 🏋️ ฟิตเนส · 🧘 โยคะ · 🪢 กระโดดเชือก | นาที ÷ `sport_minutes_for_full` (60) × `daily_cap` (5) · ต่ำกว่า `sport_min_minutes` (15) = 0 | 45 นาที → 3.75 · 14 นาที → 0 |

ตัวเลขในวงเล็บคือค่าปัจจุบัน ปรับได้ที่แท็บ `config` โดยไม่ต้อง deploy

### 2. รวมต่อคนต่อวัน แล้วตัดเพดาน

- **1 คน ส่งได้ 1 กิจกรรม/วัน** (ผู้ใช้เปลี่ยน 25 ก.ย. 2569) — Apps Script ปฏิเสธรายการที่ 2 (`code: "DAY_TAKEN"`), หน้ากรอกปิดปุ่มบันทึก, ถ้าชีตมีหลายแถว (แอดมินพิมพ์เอง) `scoring.js` นับแถวแรกตามลำดับในชีต ที่เหลือขึ้น warning
- **ไม่เกิน `daily_cap` = 5 คะแนน/คน/วัน** เกินก็ได้ 5
- วิ่ง 3 + ปั่น 8 กม. (2) = 5 ✅ · วิ่งลู่ 7.5 กม. → นับ 5 · เดิน 4,000 ก้าว (2) + วิ่ง 2 กม. (2) = 4

### 3. คะแนนทีม

ผลรวมคะแนน (หลังตัดเพดาน) ของสมาชิกทุกคน ทุกวัน **× `team_size` ÷ จำนวนสมาชิก** (ค่าเริ่มต้น `team_size` = 5)

- ทีม 5 คน ×1 ไม่เปลี่ยน · ทีม 6 คน ×5/6 · ทีม 4 คน ×5/4 — เทียบทุกทีมเป็นทีม 5 คน (ตั้งแต่ 25 ก.ย. 2569 มี 37 คน ทีม C, G มี 6 คน)
- ปรับทั้งคะแนนรวม, คะแนนรายวันของทีม (🏆 ชนะวัน), กราฟ, สนามแข่ง · `t.rawPts` = ผลรวมจริงก่อนปรับ (โชว์ในหน้ารายทีม และใช้ใน "คะแนน รวมทุกคน" ของโพเดียม)
- คะแนนรายคน / ผลการ์ด (c.effect) เป็นคะแนนของคน ไม่ปรับสัดส่วน
- ป้าย 🔁 ทีมสม่ำเสมอ ดูเป็นสัดส่วนของทีม (≥ 60%) ไม่ใช่จำนวนคน
คะแนนเต็มทั้งกิจกรรม = จำนวนคน × 5 × จำนวนวัน (5 × 5 × 51 = 1,275)

### 4. รายการที่ไม่นับ (ขึ้นกล่องเตือนเหลืองพร้อมเลขแถว)

- ชื่อไม่อยู่ในแท็บ `teams` (เทียบแบบไม่สนตัวพิมพ์ใหญ่-เล็ก)
- วันที่นอกช่วง `start_date`–`end_date` หรืออ่านไม่ออก (รับ `2026-09-15`, `15/9/2026`, `15/09/2569`)
- กิจกรรมสะกดไม่ตรง (รับ run/วิ่ง/วิ่งสวน · treadmill/วิ่งลู่ · walk/เดิน · bike/ปั่น/จักรยาน · badminton/แบด/ตีแบด · tennis/เทนนิส · football/ฟุตบอล/เตะบอล · swim/ว่ายน้ำ · basketball/บาส · gym/ฟิตเนส/ยิม/เวท · yoga/โยคะ · jumprope/กระโดดเชือก)
- จำนวน ≤ 0 หรืออ่านไม่ออก (รับ `5,000`)

### 5. ค่าที่แสดงประกอบ

| ค่า | วิธีคิด |
|---|---|
| อันดับ | เรียงคะแนนทีม เท่ากันได้อันดับเดียวกัน |
| 👑 ผู้นำ / ห่างผู้นำ | คะแนนผู้นำ − คะแนนทีม |
| ▲▼ | อันดับวันนี้เทียบอันดับสะสมถึงเมื่อวาน |
| 🔥 มาแรงวันนี้ | ทีมที่ได้คะแนนสูงสุดในวันล่าสุด |
| 🏆 ชนะวัน | ทีมที่ได้คะแนนสูงสุดของวันนั้น (เสมอได้หลายทีม) นับสะสมเป็น "ชนะ (วัน)" |
| ⭐ ดาวประจำวัน | คนที่ได้ **คะแนนดิบก่อนตัดเพดาน** สูงสุดของวัน — ใช้ค่าดิบเพราะค่าหลังตัดจะเสมอที่ 5 เกือบทุกวัน "ทำได้ 8.77" คือค่าดิบ ส่วนที่นับจริงยัง 5 · 🔥 N วันติด = เป็นดาวติดต่อกัน |
| นักวิ่งเด่น | Top 3 คะแนนสะสมรายคนรวมทุกทีม |
| สนามแข่ง | ตำแหน่ง = คะแนนทีม ÷ คะแนนเต็มทั้งกิจกรรม · เส้นประ = วันที่ผ่านไป ÷ วันทั้งหมด · เลนเรียง A–G |
| ส่งผล x/y วัน | วันที่คนนั้นมีรายการ ÷ วันที่ผ่านไป |
| คนส่งผล x/35 | คนที่มีรายการในวันล่าสุด |
| แถบในการ์ดทีม | คะแนนทีม ÷ (`team_size` × 5 × วันที่ผ่านไป) |

### 6. การ์ดพิเศษ (แท็บ `cards`)

ทีมละ **3 ใบต่อวีค** (จันทร์–อาทิตย์) ชนิดละ 1 ใบ · **วันละ 1 ใบต่อทีม** · ใช้กับ**วันที่กดเท่านั้น** · ใช้แล้วยกเลิกไม่ได้ · ใช้ไม่หมดไม่ทบ

| การ์ด | ผล | รายละเอียด |
|---|---|---|
| 🎒 เดอะแบก `carry` | โอนส่วนเกินให้เพื่อน | โอนได้เฉพาะ **ส่วนที่เกินเพดาน** ของผู้ให้ และ **สูงสุด = เพดาน (5)** · ผู้ให้ยังได้ 5 · ผู้รับยังติดเพดาน 5 · วิ่ง 15 → ตัวเอง 5 + เพื่อน 5 ที่เหลือหาย |
| ✖️2 คูณสอง `x2` | ×2 เกินเพดานได้ | **ระบบสุ่ม**สมาชิกในทีมตอนกดใช้ ล็อกชื่อทันที · คะแนนวันนั้น ×2 **สูงสุด 10** (วิ่ง 3 → 6, วิ่ง 5 → 10) · สุ่มได้คนที่ไม่วิ่ง = เสียเปล่า |
| 🛡️ Block `block` | คนที่โดน = 0 | เลือกทีมอื่น + คน 1 คน · **เฉลยหลังจบวัน** (ระหว่างวันคะแนนแสดงปกติ ข้ามวันค่อยหัก) · 2 ทีม block คนเดียวกันได้ ต่างทีมไม่รู้กัน · **block ชนะทุกอย่าง** — โดนแล้วต่อให้มี x2 หรือรับเดอะแบกก็ 0 |

ลำดับคำนวณต่อคนต่อวัน: **block → carry → x2 → เพดาน**
(carry คิดจากค่าดิบก่อน x2 เพื่อไม่ให้ x2 ขยายส่วนที่โอนไปแล้ว)

### 7. ป้ายพิเศษ / ฉลอง / โพเดียม (แสดงผลอย่างเดียว ไม่กระทบคะแนน)

**ป้ายสนุกในการ์ดทีม** — คำนวณใน `js/scoring.js` (ส่วน "ป้ายสนุก ๆ") ทีมที่เข้าเงื่อนไข**มากที่สุด**ได้ป้ายนั้น (เสมอกันได้ทุกทีม) ทีมหนึ่งได้หลายป้ายได้

| ป้าย | เงื่อนไข |
|---|---|
| 🐦 ทีมตื่นเช้า | สัดส่วนรายการที่กรอกก่อน 8:00 สูงสุด (≥30% จาก ≥10 รายการที่มีเวลา) |
| 🦉 ทีมกลางคืน | สัดส่วนรายการที่กรอกหลัง 21:00 สูงสุด (เงื่อนไขเดียวกัน) |
| 🏆 นักล่าสเตจ | ชนะรายวันมากที่สุด (≥2 วัน) |
| 🎯 การ์ดแม่น | ใช้การ์ดแล้วได้ผลทุกใบ ไม่มีใบเสียเปล่า (≥2 ใบ) |
| 🛡️ เป้าสายตา | โดน block มากที่สุด (≥2 ครั้ง นับใบที่มีผล ไม่นับซ้อน) |
| 🔁 ทีมสม่ำเสมอ | สมาชิกที่ส่งผล ≥80% ของวันมีมากที่สุด (≥3 คน หลังผ่านไป ≥5 วัน) |

เวลาที่กรอกอ่านจากคอลัมน์ `submitted_at` (มีเฉพาะรายการที่กรอกผ่านหน้าเว็บ)

**ฉลอง** (แถบ + confetti ครั้งแรกที่เห็นต่อเครื่อง) เมื่อวันล่าสุดมี: ผู้นำเปลี่ยนมือ · x2 ได้เต็ม 2×เพดาน · ทีมชนะรายวัน ≥3 วันติด · block ตัด ≥2×เพดาน
**3 วันสุดท้าย** ข้อความ "เหลืออีก N วัน" ในแบนเนอร์เป็นสีทองกระพริบ + 🔥
**โพเดียม** ขึ้นบนสุดหน้าอันดับเมื่อ `วันนี้ > end_date`: นักกีฬา 3 คน (เสื้อสีทีม+เหรียญ) ยืนบนแท่น + MVP (คะแนนสะสมรายคนสูงสุด) + กม./ก้าว/คะแนนรวมทุกคน · ระหว่างแข่งเปิดดูตัวอย่างได้จากลิงก์ท้ายหน้า (`?podium=1`) หน้าตาเหมือนของจริง · เฉลย block ดูได้ในตาราง "การ์ดวีคนี้" (ไม่มีแถบเฉลยแยก)
**▶ ย้อนดู** เล่นตำแหน่งสนามแข่งทีละวันจากวันแรกถึงวันนี้

### 8. หน้ากรอกตรวจเพิ่มก่อนลงชีต

PIN ตรงทีม · ชื่ออยู่ในทีมนั้น · วันที่ไม่ก่อนเริ่ม/ไม่ล่วงหน้า (เวลาไทย) · ระยะ ≤ 300 กม. · ก้าว ≤ 100,000

โค้ดคำนวณอยู่ที่ `js/scoring.js` ไฟล์เดียว — สคริปต์ฝั่ง Google ตรวจแค่ความถูกต้องของรายการ ไม่ได้คิดคะแนน
